# 🌌 Интерактивная Солнечная система

Интерактивная обучающая демонстрация Солнечной системы, созданная с использованием React, TypeScript и Tailwind CSS.

https://delusion-impact.github.io/experiments_galaxy_model/


![Solar System Demo](./public/solar-system-preview.svg)

## ✨ Возможности 

- **8 планет** с реалистичными относительными орбитальными скоростями
- **Спутники планет** — Луна, Фобос, Деймос, галилеевы спутники Юпитера, Титан и другие
- **Интерактивная информация** — нажмите на планету для просмотра характеристик
- **Управление воспроизведением** — пауза/воспроизведение
- **Регулятор скорости** — от 0.01× до 10×
- **Режим приближения (Zoom)** — фокус на выбранной планете с отслеживанием; без выбора приближает центр системы
- **Переключатель спутников** — включение/отключение отображения лун
- **Intruders** — запуск UFO, которое летит к случайной планете по участкам с ускорением и сменой направления
- **Разрушение планет** — столкновение сопровождается вспышкой, энергетическими волнами и разлетающимися осколками
- **Чёрная дыра** — появляется, когда планет не остаётся, и поглощает UFO
- **Красивый космический дизайн** с анимированными звёздами

## 🚀 Быстрый старт

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера
npm run dev

# Сборка для продакшена
npm run build
```

## 🎮 Управление

- **Клик по планете** — показывает информационную панель с характеристиками
- **Пауза/Старт** — останавливает или запускает анимацию
- **Приблизить/Отдалить** — зум к выбранной планете с автоматическим отслеживанием; если планета не выбрана, зум центрируется на Солнце
- **Спутники ВКЛ/ВЫКЛ** — переключает отображение лун и их орбит
- **Скорость** — регулирует скорость движения планет (0.01× — 10×); скорость спутников и UFO от неё не зависит
- **Intruders** — запускает UFO в случайной точке; каждая тарелка выбирает планету-цель и гарантированно врезается в неё. Если планет больше нет, UFO улетают в чёрную дыру
- **Кнопки планет** — быстрый выбор планеты внизу экрана

## 🛠 Технологии

- **React 18** — UI-фреймворк
- **TypeScript** — типизация
- **Tailwind CSS** — стилизация
- **Vite** — сборщик
- **requestAnimationFrame** — плавная анимация 60 FPS

## 📐 Расчёт скоростей

Скорость анимации привязана к орбитальному периоду Земли:
- При `speed = 1×` Земля совершает **1 оборот за 60 секунд**
- Остальные планеты пересчитаны пропорционально их реальным орбитальным периодам
- Настройка скорости применяется только к планетам
- Спутники и UFO движутся независимо от выбранной скорости; кнопка «Пауза/Старт» останавливает и запускает всю анимацию
